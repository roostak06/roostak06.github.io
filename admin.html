اتصال و راهنما

پنل به پروژهٔ Supabase متصل می‌شود. برای اعمال تغییرات، سیاست‌های دسترسی دیتابیس باید از قبل درست تنظیم شده باشند.

برای مدیریت دسته‌ها از بخش «مدیریت دسته‌بندی‌ها» استفاده کن. ابتدا migration فایل supabase-roostak-features.sql را اجرا کن.

امنیت

  • هرگز کلید service_role را در فایل‌های مرورگر قرار نده.
  • دسترسی مدیر باید در سمت دیتابیس بررسی شود، نه فقط با مخفی‌کردن دکمه‌ها.
  • برای عکس‌های عمومی از bucket محصولات استفاده کن و اطلاعات تماس خصوصی را در جدول عمومی قرار نده.
